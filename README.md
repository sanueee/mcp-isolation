# Изоляция локальных MCP-серверов: runc vs gVisor

Студенческое исследование: как выданные полномочия и среда выполнения контейнера
влияют на доступ локального MCP-сервера к ресурсам Linux-хоста.

**Исследовательский вопрос.** Какие из 3–4 известных сценариев доступа к ресурсам
Linux-хоста воспроизводятся на актуальных версиях runc и gVisor при фиксированных
условиях, и как меняется исход после удаления избыточных полномочий?

**Срок:** ноябрь 2026 — май 2027
